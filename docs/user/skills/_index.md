Skill 是 Semantic 中可复用的领域能力。用户可以查看其状态、选择版本并诊断加载或执行问题。

- [Skill 的使用与调试](use-and-debug.md)

![Skill 库](../../../static/images/user/getting-started/agent-skill-library.png)

Skill 模块帮助你区分 Agent Skill 和 Robot Skill：前者影响 Agent 如何规划，后者影响 Robot 如何执行。
