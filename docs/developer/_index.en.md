The Developer Guide is for engineers extending Semantic.

Development areas include:

- Agent Skills and tools;
- Workflow and task orchestration;
- Robot Skills, Abilities, and Robot SDK adapters;
- Simulation Scenes and Runtime packages;
- Semantic Studio integration;
- Build, test, bundle, and release workflows.

The detailed developer pages are currently maintained in Chinese. English developer pages can be added incrementally using the same `.en.md` translation-file pattern used by the User Guide.
